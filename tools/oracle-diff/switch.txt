# switch モード: Switch ～ EndSw の各ブロックで飛び込む Case の行 (0 始まり、無ければ end)。

Set 名前 リオ
Set n 5
Set s "05"
Set half 1.5
Set 空 ""
Set 配列[1] alpha
Set 配列[2] beta
Set idx 2
